
jemplos de Preguntas de Examen de SQL

• Selección básica de datos:
	• Pregunta: ¿Cuál es la sintaxis correcta para seleccionar todos los registros de la tabla employees donde el salario sea mayor a 50,000?
	• Opciones típicas:
		• A) SELECT * FROM employees WHERE salary > 50000; (Correcta)
		• B) SELECT salary FROM employees WHERE salary 50000;
		• C) SELECT FROM employees WHERE salary = 50000;
• Modificación de tablas (DDL):
	• Pregunta: ¿Qué comando se utiliza para cambiar la estructura de una tabla existente (por ejemplo, agregar una columna)?
	• Opciones típicas:
		• A) DELETE TABLE
		• B) ALTER TABLE (Correcta)
		• C) UPDATE TABLE
• Filtrado de duplicados:
	• Pregunta: ¿Qué palabra clave se usa para asegurar que un resultado devuelva únicamente valores únicos?
	• Opciones típicas:
		• A) UNIQUE
		• B) DISTINCT (Correcta)
		• C) GROUP
• Funciones de agregación:
	• Pregunta: ¿Qué función calcula el valor promedio de una columna numérica?
	• Opciones típicas:
		• A) SUM()
		• B) AVG() (Correcta)
		• C) COUNT()
• Unión de tablas (Joins):
	• Pregunta: ¿Qué tipo de JOIN devuelve únicamente los registros que tienen una coincidencia en ambas tablas?
	• Opciones típicas:
		• A) INNER JOIN (Correcta)
		• B) LEFT JOIN
		• C) OUTER JOIN
