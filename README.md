• Tipos de datos: enteros (INT, BIGINT), decimales, cadenas (VARCHAR, CHAR, TEXT), fechas y booleanos.
• Consultas básicas (DQL): SELECT, FROM, WHERE, operadores lógicos y de comparación, LIKE, IN, BETWEEN, ORDER BY y LIMIT.
• Manipulación de datos (DML): INSERT INTO, UPDATE y DELETE. [1] (https://translate.google.com/translate?u=https://www.linkedin.com/pulse/list-sql-topics-follow-comprehensive-end-learning-shubhrajit-basu-36ewc&hl=es&sl=en&tl=es&client=sge), [2] (https://translate.google.com/translate?u=https://www.superdatascience.com/blogs/blog-10-essential-topics-to-understand-sql&hl=es&sl=en&tl=es&client=sge), [3] (https://learnsql.es/blog/terminos-de-sql-que-los-principiantes-deben-conocer/), [4] (https://www.youtube.com/shorts/jlWxO5Xf1wQ), [5] (https://www.youtube.com/shorts/zMVRWyl1wiw)

2. Agrupación y combinación de tablas

• Funciones de agregado: COUNT, SUM, AVG, MIN y MAX.
• Agrupación y filtros de grupos: GROUP BY y HAVING.
• Uniones (JOIN): INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN y CROSS JOIN para combinar datos de varias tablas.
• Operadores de conjuntos: UNION, UNION ALL, INTERSECT y EXCEPT.
• Subconsultas: consultas anidadas en SELECT, WHERE o FROM. [1] (https://www.reddit.com/r/SQL/comments/19eob3d/what_would_you_consider_a_basic_knowledge_of_sql/?tl=es-419), [2] (https://translate.google.com/translate?u=https://www.superdatascience.com/blogs/blog-10-essential-topics-to-understand-sql&hl=es&sl=en&tl=es&client=sge), [3] (https://www.youtube.com/shorts/jlWxO5Xf1wQ)

3. Definición de estructuras y control

• Definición de datos (DDL): CREATE TABLE, ALTER TABLE, DROP TABLE y restricciones (NOT NULL, UNIQUE, CHECK, DEFAULT).
• Transacciones (TCL): BEGIN / START TRANSACTION, COMMIT, ROLLBACK y propiedades ACID.
• Control de acceso (DCL): usuarios, roles, GRANT y REVOKE.
• Vistas: CREATE VIEW y vistas materializadas para encapsular consultas frecuentes. [1] (https://www.youtube.com/watch?v=DFg1V-rO6Pg), [2] (https://www.youtube.com/shorts/krpC4gmKjuU), [3] (https://www.ibm.com/docs/es/db2w-as-a-service?topic=reference-statements)

4. SQL avanzado y optimización

• CTE y recursividad: expresiones de tabla comunes (WITH) y consultas recursivas.
• Funciones de ventana: ROW_NUMBER(), RANK(), DENSE_RANK(), NTILE(), LAG() y LEAD().
• Objetos programables: procedimientos almacenados, funciones definidas por el usuario y disparadores (TRIGGERS).
• Manejo de errores y JSON/XML: bloques TRY...CATCH, SQL dinámico y consulta de datos semiestructurados.
• Rendimiento: índices (B-tree, compuestos), planes de ejecución y optimización de consultas. [1] (https://translate.google.com/translate?u=https://medium.com/@AnweshaB/14-topics-to-cover-in-sql-6058441411fc&hl=es&sl=en&tl=es&client=sge), [2] (https://www.youtube.com/watch?v=DFg1V-rO6Pg)
